# Results figures

All figures produced by this project's code are vector files (`.svg`), written by the helpers in
`src/*/plots.py` and the stage scripts in `scripts/`.

`feature_974_neuronpedia.png` is the one exception on purpose: it is a **screenshot** of Neuronpedia's
own page for Feature 974 (an external tool, not generated by this project).

Older `.png` files in this folder and its subfolders were produced before the switch to SVG. They are
replaced the next time the stage that made them is re-run; delete the `.png` once its `.svg` exists.
